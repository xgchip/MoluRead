# 阅读页优化：第一版

## 设计方向

参考 [Ghost的字体与设计设置](https://ghost.org/help/design-settings/) 对阅读体验的区分，以及 [WordPress标签云](https://developer.wordpress.org/reference/functions/wp_tag_cloud/) 按使用频次显示权重的方式。这里的具体字号、间距、动态效果为本主题的设计选择，并非照搬参考站。

- 文章默认不使用顶部大封面，标题居中；首页卡片缩略图和正文图片保留。
- 标题25–34px，手机26px；信息行桌面12px/手机11px，图标13px。
- 正文16px、1.9–1.95行高，段落有独立留白；长标题、代码及图片不撑破手机宽度。
- 侧栏标题14px，文章列表13px，阅读数10px；排行号固定宽度，标题最多两行，数字靠右。
- 博主头像58px，简介12px，统计模块分离标签和数值。
- 标签区命名“标签云”，根据文章数分配12–16px字号。动态模式用真实HTML链接投影形成缓慢旋转的文字云，不加载外部库或第三方服务。

## 主题设置

“文章页面封面图”默认关闭，仍可由站长手动开启。新增“标签云样式”设置：动态/静态，位于主题设置侧栏分区。

动态标签云可用按钮暂停/继续；鼠标停留和键盘焦点进入时暂停，离开后恢复。页面不可见或标签云不在视口时停止动画；系统开启减少动态效果时显示静态标签。JavaScript不可用时仍为可点击、可换行的静态链接。

## 源码

- components/post-content.php：语义化标题和文章信息行。
- components/widgets/widget-tags.php：标签数据、权重、链接及模式开关。
- assets/css/reading.css：独立阅读与侧栏样式。
- assets/js/tag-cloud.js：无依赖动态标签云。
- components/header.php / footer.php：直接加载上述源文件，通过既有filemtime更新缓存；本次没有另外生成min产物。
- core/theme-config.php：封面默认值及标签云选项。

保留已有主题补丁、作者署名和许可。站点自己的Logo、轮播和后台配置不进入可分发主题。

## 本次验证

按用户选择，本地只编辑源码，备份后上传获授权的网站检查。PHP文件语法、JS语法及git diff --check通过。浏览器确认标题居中、信息行12px、无头图、10个标签链接和暂停切换；390px宽度页面无横向溢出，手机标题26px、信息行11px，深色模式已查看。

首页、散文与技术文章、分类、标签、分页及公众号健康接口均HTTP200。对比备份数据库，195篇文章的标题、链接标识、时间、正文及状态完全一致。没有提交测试评论或修改文章。减少动态效果和禁用JS的回退已实现并检查代码，本次未切换操作系统设置进行实测。
